# Dynamic ADMIN+

A powerful and modern **Admin GUI plugin** for Minecraft servers.  
Dynamic ADMIN+ converts player management into a fast, visual, and intuitive experience using elegant **double-chest interfaces**.

---

## ✨ Features

### 🧭 GUI-Based Player Management
- View and select online players
- Clean double-chest layouts
- Customizable titles, items, and interface visuals

### 🎯 Player Actions
Easily perform essential moderation tasks:
- **Ban**
- **Kick**
- **Teleport to player**
- **Teleport player to you**
- **Kill**
- **Remove potion effects**
- **Modify max health**
- **Freeze / Unfreeze**

Includes **self-protection** to prevent targeting yourself.

### 🔐 Confirmation System
All destructive actions (ban, kick, kill, etc.) require confirmation to avoid mistakes.

### 🚀 Performance-Focused Caching
- Configurable refresh intervals  
- Cache expiry timers  
- Max entries  
- Optional preload  
Optimized for smooth performance even on active servers.

### 🎨 Fully Customizable
- Editable messages with color codes & placeholders (`%player%`, `%health%`)  
- Custom GUI item materials  
- Toggleable features  
- Custom sound effects for interactions  
- Permission overrides

### 🛡 Granular Permissions
- dynamicadminplus.use
- dynamicadminplus.ban
- dynamicadminplus.kick
- dynamicadminplus.teleport.to
- dynamicadminplus.teleport.here
- dynamicadminplus.kill
- dynamicadminplus.remove.potions
- dynamicadminplus.modify.health
- dynamicadminplus.freeze
- dynamicadminplus.unfreeze


### 🐞 Debug Mode
Optional detailed logging for debugging or development.

---

## 📦 Command

### `/da players`
Opens the main player selection GUI.  
Requires: `dynamicadminplus.use`
